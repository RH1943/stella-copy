# 스텔라 복사기 · Stella Copy 1.0.0

**[설치 ZIP 다운로드 · Releases](https://github.com/RH1943/stella-copy/releases/latest)**

릴리스의 `stella-copy-1.0.0.zip`을 받으세요. `Source code (zip)`은 개발 소스 묶음입니다.

스텔라의 **현재 세션·현재 분기**를 클립보드에 복사하는 옵시디언 플러그인입니다.
채팅은 전체·번호 범위, 소설은 본문 전체 복사를 지원합니다.

## 설치 — 빌드할 필요 없습니다

1. ZIP을 풀면 나오는 `stella-copy` 폴더를 사용합니다.
2. 그 폴더를 볼트의 `.obsidian/plugins/` 안에 넣습니다.
3. 최종 위치가 아래와 같은지 확인합니다. 폴더가 두 겹으로 중첩되지 않게 하세요.

   - `<볼트>/.obsidian/plugins/stella-copy/main.js`
   - `<볼트>/.obsidian/plugins/stella-copy/manifest.json`
   - `<볼트>/.obsidian/plugins/stella-copy/styles.css`

4. 옵시디언을 다시 열고 **설정 → 커뮤니티 플러그인 → Stella Copy · 스텔라 복사기**를 활성화합니다.
5. 기존 스텔라 엔진도 활성화한 뒤 채팅이나 소설 세션을 엽니다.

설치에 필수인 파일은 위 3개입니다. 나머지 파일은 설명서·개발 소스입니다.
기존 스텔라 엔진 폴더를 교체하거나 엔진 소스를 수정할 필요는 없습니다.
이 ZIP은 옵시디언 플러그인용이며 SillyTavern의 확장 설치 칸에 넣는 파일이 아닙니다.

## 사용

세션 하단의 **퍼즐 아이콘(확장 기능)**을 누릅니다.

| 메뉴 | 동작 |
|---|---|
| 전체 원문 복사 / Copy all | 채팅 전체 또는 소설 전체를 복사합니다. 채팅에는 기본적으로 화자 이름이 붙습니다. |
| 번호 범위·미리보기 / Range & preview | 결과를 확인하고, 채팅 번호 범위와 화자 이름·번호 표시 여부를 선택합니다. |

옵시디언 **명령어 팔레트**에서 `Stella Copy`를 검색해도 같은 두 명령이 나옵니다.
단축키는 옵시디언의 단축키 설정에서 지정할 수 있습니다.

### 채팅 범위 복사 예시

1. **번호 범위·미리보기**를 엽니다.
2. 복사 범위를 **번호 범위 / Number range**로 바꿉니다.
3. 시작 `10`, 끝 `20`을 입력하면 **10~20번, 총 11개 메시지**를 복사합니다.
4. **복사 / Copy**를 누릅니다.

첫 메시지는 **0번**입니다. 번호를 확인하려면 **메시지 번호 / Numbers**를 켜고 전체 미리보기를 보세요.
숨김 메시지도 번호에 포함됩니다. 삭제된 메시지는 제외되고 번호가 다시 매겨지므로, 편집·삭제·분기 변경 후에는 다시 불러오세요.

소설에서는 범위 입력 없이 전체 본문이 표시됩니다. 원문의 공백·줄바꿈도 보존합니다.

## 정확한 복사 범위

- 현재 선택한 세션에서 루트부터 활성 분기 끝까지 복원한 **원문 텍스트**입니다. 화면에 아직 표시되지 않은 오래된 메시지도 포함합니다.
- **‘AI에게 숨김’ 내용도 포함**합니다. 이 기능은 AI 전송용 컨텍스트 추출이 아닌 사용자용 원문 복사입니다.
- 편집·삭제 결과를 반영하고, 선택하지 않은 재생성 분기와 삭제 이전의 이력은 포함하지 않습니다.
- 다른 세션이나 다음 화를 한꺼번에 합치지 않습니다.
- 번역 보기, 표시 전용 정규식, 표시용 매크로 확장, HTML 렌더 결과는 적용하지 않습니다. 태그·마크다운·매크로는 원문 형태로 남습니다.
- 이미지 파일, 첨부 이미지의 별도 정보, 삽화, 메모, 요약은 복사 대상이 아닙니다.
- 채팅 입력창의 아직 **보내지 않은 메시지**는 제외됩니다. 기존 본문/말풍선의 편집은 엔진의 저장 경로로 먼저 확정합니다.
- 일반 소설 및 PRO 세션 모두 저장된 원문 기준입니다. PRO 편집의 AI 변환이나 양방향 번역 반영을 복사 때문에 새로 실행하지 않습니다. 해당 작업이 대기 중이면 먼저 스텔라에서 완료하세요.
- 채팅 화자 이름은 세션의 현재 페르소나, 시나리오/그룹 화자, 익명 화자 이름을 사용합니다. 과거에 사용했던 페르소나 이름을 메시지별로 복원하는 기능은 없습니다.
- 미리보기는 불러온 시점의 고정된 내용입니다. 이후 변경 사항은 **다시 불러오기 / Reload**로 반영합니다. 새로 불러오면 번호 범위는 초기화됩니다.

## 문제 해결

- **자동 복사가 안 됨:** 미리보기에서 **텍스트 선택 / Select text**를 누르고 PC는 `Ctrl+C` / `Cmd+C`, 모바일은 기기의 복사 메뉴를 사용합니다.
- **진행 중인 작업 안내:** 스텔라에서 생성·번역·삽화 등의 작업이 끝난 뒤 다시 누릅니다.
- **복사 메뉴가 안 보임:** 스텔라와 복사기가 모두 활성화되었는지 확인합니다. 스텔라를 늦게 활성화했으면 약 2초 후 퍼즐 메뉴를 다시 열거나 명령어 팔레트를 사용합니다.
- **번호 오류:** 시작·끝 모두 정수로 입력하고, `0 ≤ 시작 ≤ 끝 ≤ 마지막 번호`인지 확인합니다.
- **다른 엔진 버전:** 즉시 복사 대신 미리보기를 열어 확인하게 합니다. 필요한 메서드나 세션 구조가 맞지 않으면 오류를 표시하고 복사를 중단합니다.

## 호환성과 검증 범위

- 첨부된 **GGAI Stella Engine 0.0.46**, 세션 스키마 1의 실제 소스를 기준으로 제작했습니다. 옵시디언 최소 버전은 해당 엔진과 같은 1.5.0으로 지정했습니다.
- 데스크톱·모바일용으로 작성했으며 화면은 좁은 폭에 맞춰 줄바꿈됩니다. 다만 **실제 옵시디언/휴대폰 설치 실기 검증은 이 환경에서 수행하지 못했습니다.**
- TypeScript 검사와 배포용 빌드 성공. 분기·패치·범위·숨김·긴 대화 등을 확인하는 자동 테스트 10개 통과. 구체적인 내용은 `VALIDATION.md`를 보세요.
- 엔진 내부 조회 메서드를 사용하는 호환 어댑터가 있으므로 향후 엔진 업데이트에 대한 무조건적인 호환성을 보장하지 않습니다.
- 복사기 자체는 AI를 호출하거나 외부로 데이터를 전송하지 않습니다. 별도 모델·API 키 설정도 없습니다. 기존 스텔라가 요구하는 설치 조건은 그대로 적용됩니다.

## 개발 및 근거 소스

```sh
npm ci
npm run build
npm test
```

`npm run build`는 타입 검사 후 `main.js`를 만듭니다. `npm test`에는 Node.js 18 이상이 필요합니다.

| 파일 | 역할 |
|---|---|
| `src/main.ts` | 옵시디언 명령·스텔라 액션 등록과 해제 |
| `src/adapter.ts` | 엔진 조회·편집 확정·이름 조회·복사 스냅샷 |
| `src/vendor/session-text.ts` | 첨부 엔진의 본문 패치 복원 로직 |
| `src/vendor/chat-messages.ts` | 첨부 엔진의 메시지·역할 복원 로직 |
| `src/copy-text.ts` | 세션 구조 검증, 번호 범위, 복사 형식 |
| `src/copy-modal.ts` | 복사 범위·미리보기 화면 |
| `src/clipboard.ts` | 클립보드와 실패 시 대체 처리 |

근거는 사용자가 첨부한 다음 원본입니다. 온라인 최신판을 검증했다는 의미는 아닙니다.

- `ggai-plugin-starter-main (1).zip`: `src/stella-api.ts`, `docs/stella-extension-hooks.md`, 빌드 설정. 공개 저장소: <https://github.com/0ogg/ggai-plugin-starter>
- `GGAI-STELLA-ENGINE-main.zip`: `manifest.json`, `src/main.ts`, `src/state/store.ts`, `src/util/session-text.ts`, `src/util/chat-messages.ts`, `src/views/session-host.ts`, `src/types/node-meta.ts`.
- `ggang-copy-main.zip`: 0부터 시작하는 메시지 번호·양 끝 포함 범위 동작을 참고했습니다. 원본의 다른 부가기능은 이식하지 않았습니다.

## 제거

옵시디언에서 복사기를 비활성화하고 `stella-copy` 폴더를 삭제합니다. 이 플러그인은 별도 세션 데이터나 설정 파일을 만들지 않습니다.
